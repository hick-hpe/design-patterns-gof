# Design Patterns GoF

Este repositório apresenta exemplos de três padrões de projeto (Design Patterns) do catálogo GoF (Gang of Four), contemplando um padrão de cada categoria: criacional, estrutural e comportamental.

## Tipos de padrões
- **Padrões Criacionais**:
Os padrões criacionais cuidam dos mecanismos de criação de objetos. Eles ajudam a tornar o sistema flexível ao decidir quais objetos criar para uma situação específica. <br/>
Padrão utilizado: Prototype.

- **Padrões Estruturais**:
Os padrões estruturais explicam como montar classes e objetos em estruturas maiores, mantendo a eficiência e a flexibilidade. <br/>
Padrão utilizado: Proxy.

- **Padrões Comportamentais**:
Os padrões comportamentais focam em algoritmos, na atribuição de responsabilidades e na comunicação eficiente entre os objetos. <br/>
Padrão utilizado: Prototype.

## Padrões escolhidos

- **Prototype**: Cria novos objetos através da clonagem de um exemplar existente.

- **Proxy**: Fornece um substituto ou placeholder para outro objeto, permitindo controlar o acesso a ele.

- **Strategy**: Define uma família de algoritmos, encapsula cada um deles e os torna intercambiáveis dentro do mesmo contexto.
